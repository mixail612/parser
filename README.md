# Парсер объявлений Avito

Этот проект представляет собой Telegram-бот, который отслеживает новые объявления на сайте Avito.ru по заданным URL-адресам. Бот использует Selenium и BeautifulSoup для парсинга страниц, сохраняет данные о просмотренных объявлениях в базе данных SQLite и отправляет уведомления о новых объявлениях пользователю в Telegram.

Бот работает в фоновом режиме с использованием многопоточности для одновременного парсинга нескольких URL, с настраиваемыми задержками, чтобы избежать перегрузки сайта или блокировки.

## Функции

- **Отслеживание нескольких URL**: Добавляйте URL поисковых страниц Avito для мониторинга новых объявлений.
- **Уведомления о новых объявлениях**: Отправляет сообщения в Telegram с ценой и ссылкой на новые объявления.
- **Хранение данных в базе**: Использует SQLite для сохранения URL просмотренных объявлений и отслеживаемых ссылок.
- **Настраиваемые параметры**: Контролируйте количество сообщений на один URL, задержки между проверками и загрузкой страниц.
- **Многопоточность**: Каждый URL обрабатывается в отдельном потоке для повышения эффективности.
- **Команды Telegram**: Управляйте ботом через команды в Telegram.

## Требования

- Python 3.6+, убедитесь, что python и pip добавлены в path.
- Установленный браузер Chrome (для Selenium).
- ChromeDriver (скачайте с [официального сайта](https://chromedriver.chromium.org/downloads), версия должна соответствовать вашему Chrome).
- Зависимости, указанные в `requirements.txt`.

## Установка

1. Клонируйте или скачайте репозиторий.

2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
   Если вы запускаете под linux, то
   ```
   pip3 install -r requirements.txt
   ```

4. Скачайте ChromeDriver:
   - Перейдите на [страницу загрузки ChromeDriver](https://chromedriver.chromium.org/downloads).
   - Скачайте версию, соответствующую вашему браузеру Chrome.
   - Поместите файл в известный путь (например, `C:/chromedriver/chromedriver.exe` на Windows).

## Настройка

1. Создайте или отредактируйте файл `config.txt` в корне проекта. Пример содержимого:
   ```
   токен бота: ВАШ_ТОКЕН_ТЕЛЕГРАМ_БОТА
   id пользователя: ВАШ_ID_ПОЛЬЗОВАТЕЛЯ
   максимальное количество сообщений за 1 раз по 1 ссылке: 5
   задержка между проверкой ссылки на общее количество ссылок (в секундах): 150
   задержка между открытием ссылок (в секундах): 15

   хромдрайвер: C:/path/to/chromedriver.exe
   ```
   - **токен бота**: Токен вашего Telegram-бота (получите у [@BotFather](https://t.me/botfather)).
   - **id пользователя**: Ваш ID пользователя в Telegram (бот будет отвечать и отправлять сообщения только этому пользователю). Узнать ID можно через [@userinfobot](https://t.me/userinfobot).
   - **максимальное количество сообщений за 1 раз по 1 ссылке**: Максимальное количество новых объявлений на одну проверку URL (по умолчанию: 5).
   - **задержка между проверкой ссылки на общее количество ссылок (в секундах)**: Множитель задержки для проверок (общая задержка = это значение * количество URL).
   - **задержка между открытием ссылок (в секундах)**: Задержка между загрузкой отдельных страниц объявлений (в текущей версии не используется, но настраивается).
   - **хромдрайвер**: Полный путь к исполняемому файлу ChromeDriver.

2. База данных (`db/tests.db`) создается автоматически при первом запуске.

## Запуск бота

1. Запустите скрипт:
   ```
   python main.py
   ```

2. Бот начнет опрашивать сообщения в Telegram. Используйте команды в Telegram для управления.

Примечание: Запускайте скрипт в среде, где он может работать непрерывно (например, на сервере, VPS или в screen/tmux на Linux). Бот использует headless-режим Chrome, поэтому графический интерфейс не требуется.

## Команды Telegram-бота

Управляйте ботом, отправляя следующие команды в Telegram:

- `/help`: Показать список доступных команд.
- `/start`: Запустить процесс парсинга (запускает потоки для каждого отслеживаемого URL).
- `/stop`: Остановить процесс парсинга (останавливает потоки корректно).
- `/restart`: Перезапустить процесс парсинга (останавливает и заново запускает).
- `/add_url`: Добавить новый URL для отслеживания. Бот запросит URL в следующем сообщении.
- `/delete_url`: Удалить отслеживаемый URL. Бот запросит ID URL (из `/dir_urls`).
- `/clean_urls`: Удалить все отслеживаемые URL.
- `/dir_urls`: Показать список всех отслеживаемых URL с их ID.

После добавления или удаления URL используйте `/restart`, чтобы применить изменения.

## Как это работает

- **Логика парсинга**: Использует Selenium для загрузки страниц Avito в headless-режиме, затем BeautifulSoup для извлечения данных объявлений (название, цена, параметры, описание, URL).
- **Отслеживание просмотренных объявлений**: Сохраняет URL просмотренных объявлений в базе данных, чтобы избежать дублирования.
- **Многопоточность**: Каждый URL обрабатывается в отдельном потоке для периодических проверок.
- **Задержки**: Настраиваемые задержки для предотвращения ограничений или блокировок со стороны Avito.

## Устранение неполадок

- **Ошибки Selenium**: Убедитесь, что путь к ChromeDriver указан правильно и версии совпадают.
- **Проблемы с базой данных**: Если файл `db/tests.db` поврежден, удалите его и перезапустите (данные будут потеряны).
- **Изменения на Avito**: Если Avito обновит структуру HTML, обновите селекторы в `pars.py`.
- **Бот не отвечает**: Проверьте токен и user_id в конфиге; убедитесь, что скрипт запущен.
